## Approved Changes Since the Mockups

-   Home cards are shorter and avoid unused lower space.
-   The Home wordmark is stacked vertically and uses the shared lock
    icon.
-   Home uses an original neon stage background with a right-edge
    microphone.
-   Active gameplay moves team and score context from the left sidebar
    to the bottom status rail.
-   Active gameplay keeps New Game and Finish Game in the top action
    bar.
-   Host controls remain in the right-side challenge panel.
-   The embedded YouTube player preserves 16:9 and receives layout
    priority.
-   Lyric Lockout branding remains visible in the top left on every
    screen.
