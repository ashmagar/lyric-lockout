# UI Design System

## Philosophy

-   Minimalistic
-   Context-first
-   Consistent
-   Premium dark theme

## Global Shell

-   Fixed-width Sidebar
-   Fixed-height Header
-   Flexible Main Content
-   Fixed-height Footer

## Sidebar

Gameplay: - Teams - Scores - Lifelines - Context

Non-gameplay: - Navigation

Same dimensions on every screen.

## Header

Only screen context. Never changes height.

## Footer

Left: status/context. Right: primary action.

## Visual Language

-   Dark background
-   Purple/Pink/Blue accents
-   Glassmorphism
-   Rounded cards
-   Large readable typography
-   TV-friendly spacing

## Reusable Components

-   Sidebar
-   Header
-   Footer
-   Team Card
-   Category Card
-   Primary Button
-   Dialogs

## Animations

200--350 ms.

Preferred: - Fade - Slide - Scale - Flip

Challenge: Video → Flip → Lyrics

Reveal: Fade in missing words, highlight briefly.

Scoreboard: Blur background, slide overlay, animate scores
independently.
