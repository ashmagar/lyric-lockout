# Lyric Lockout --- UI Master Prompt

## Read these documents in order before implementing any UI:

1.  **02_APPLICATION_UX_SPEC.md**
    -   Defines every screen and frozen MVP decisions.
    -   Do not redesign frozen screens.
2.  **03_UI_DESIGN_SYSTEM.md**
    -   Defines layout, shell, animations, reusable components, and
        visual language.
3.  **Reference Screenshots**
    -   Match them closely.
    -   Preserve spacing and proportions.

## General Rules

-   Consistency over creativity.
-   Reuse components whenever possible.
-   Never redesign a frozen screen without explicit instruction.
-   Sidebar, Header, and Footer dimensions remain consistent.
-   Avoid duplicate information.
-   Prefer context-first, minimal interfaces.
-   Build the MVP first; optimize later from real gameplay feedback.

## Implementation Workflow

1.  Read the relevant screen specification.
2.  Match the reference screenshot.
3.  Reuse existing components.
4.  Preserve the global application shell.
5.  If uncertain, choose consistency over inventing a new pattern.
